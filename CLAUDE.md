# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this is

Rayan Upadhyay's personal site (rayanupadhyay.com), hosted on GitHub Pages (`CNAME`). The **entire site is one self-contained `index.html`** (~20k lines, ~2.6 MB): inline CSS, inline vanilla JS and Three.js **r128** from cdnjs (post-processing extras load lazily from `cdn.jsdelivr.net/npm/three@0.128.0/examples/js/`). There is no build step, no framework, no package.json and no test suite. Keep it that way: everything goes inside `index.html`, and Three.js stays on r128.

The `*.rayanupadhyay.com` "little sites" (tools, study, wish, links, agribridge, research) live in **separate repos/Vercel projects**. This repo only links to them (Sites section, RayanOS, terminal `open` list, README).

## Running and checking

```bash
python3 -m http.server 8000      # serve locally; news.json needs HTTP, not file://
```

There are no tests. Before committing an edit to `index.html`, at least syntax-check every inline script:

```bash
python3 - <<'EOF'
import re
s = open('index.html', encoding='utf-8').read()
js = re.findall(r'<script(?![^>]*src)[^>]*>(.*?)</script>', s, re.S)
open('/tmp/chk.js', 'w').write('\n;\n'.join('(function(){' + x + '\n})' for x in js))
EOF
node --check /tmp/chk.js
```

For behaviour checks, drive the page headlessly with Playwright/Chromium. Click `#simpleBtn` for the simple view; the 3D room needs WebGL (`--use-gl=swiftshader`). Check phone width (390px) as well as desktop, plus light and dark themes.

## Architecture (the big picture)

- **Two views over the same content.** `#simple` (the "Simple version") holds the real content as `<section class="sec" data-s="KEY">` blocks (about, research, projects, sites, music, vinyl, writing, news, highlights, contact, vault, plus `only-panel` ones like swim and photos). Those sections are the **single source of truth**:
  - `openPanel(key)` copies a section's `innerHTML` into the room's side panel when you click an object or a dock button (`data-go="KEY"`).
  - `rosApp(k)` (RayanOS, the laptop desktop) copies sections into its windows, e.g. `sites`, `music` and `news`.
  - So when you change content, change the section, and don't rely on DOM injected into a section: it gets copied too. Visibility tweaks for the simple view belong in CSS scoped to `#simple .in>.sec` (not `.simple`: the "At a glance" sheet `#brief` reuses the `.simple` classes).
- **Simple view layout.** The simple view opens on a bento grid (`.bento` / `.bt` tiles). Each tile's `[data-more="KEY"]` opens one full section under the grid at a time (`bOpen`), and `.bback` ("↑ Top") closes it. In the simple view the little sites are opt-in only, behind the Sites tile and the `.xtoggle` button. RayanOS removes that toggle and shows them all.
- **The 3D world.** It is one big async IIFE: the room (WASD/joystick, click objects), then the city (an island: beach, sea, ferry and swimming to the other cities and to the Far Range, a mountain land you can climb; its zone `mtn` handles terrain height in `mtnStep`, because the movement code is frozen), side quests, mini-games and other worlds (`enterWorld`/`exitWorld`, `travel(dest)`). Dialogue uses `say()` and achievements use `secret()`. If WebGL/THREE fails, the page falls back to the simple view.
- **Stories: only the Mandalink one is left.** The old story modes (the Multiverse Saga comic, the Books, Meridian General with Code Black and System Failure, Kiran and the stories after the comic, The Tidy Man, the Hollow, and BERSERKER with its space worlds) were removed to make way for a seasons system. Code that still mentions them goes through small stand-ins in blocks headed `retired: …` (they report the stories as never started); don't build on those, and remove a stand-in together with its last caller. Their saved progress is cleared by the `retired stories` block. The Mandalink island story (猴王闹海岛) stays, and the phone's Story tab (`storyStarted()`) only shows once it has started.
- **Seasons.** 15 loosely linked seasons, four weeks each, starting 18 November 2026 and cycling (`seasonInfo()` in `index.html`; `?season=N` previews one). Each has its own villain, a tool or vehicle the player keeps, a permanent trace on the map, three skins and four weekly Parts (the in-game word; older notes say chapters). A season's content lives in `seasons/sNN.js`, loaded only while that season runs (with `?v=SEASON_V`; bump `SEASON_V` in `index.html` whenever a season file changes, so browsers don't reuse an old copy); it defines `window.RU_SEASON_N = R => ({ step, tab, wire })` and gets everything it needs from the page through the API object `R` (`seasonApi()`), never by reaching into page internals. That is the one exception to "everything goes inside `index.html`" (season files, plus `seasons/s01-trailer.mp4`, which only downloads when someone presses play). After a season ends its file is loaded again with `{ past: true }` and only builds what it left on the map (Crash Isle with its lit core and ferry stop, for Season 1); list every season that has a file in `SEASON_FILES`. Progress is saved under `ru-season` (one key per season, e.g. `s1`), and the player's name under `ru-heroname` (16 characters, cleaned by `cleanName()`, default "Traveller"). The phone has a Season tab. All villains, aliens and skins are original (no Marvel or DC characters). Real winter (December to early January) stays a bonus layer on top of whatever season is running.
- **Season 1 · Landfall** (`seasons/s01.js`): the first time you're out on the street (however you got there) a cutscene plays once: a meteor crosses the city and crashes into the sea off the west coast, with a "Skip scene" button. A meteor past the bedroom window hints at it for visitors who stay in the room. A beacon then leads to the ferry pier, where the Keeper gives you the scanner (N, or the Scan button) and three fragments wait on the beaches. Parts unlock weekly (`?week=N` previews a later one). Part 2 (Salvage): the Salvager's scrapper drones race you to four more fragments, scanning near a drone jams it, and his barge anchors offshore. Part 3 (Crash Isle): a new island rises at the impact (reached by ferry or swimming through `ISLE.stops`, walkable through `ISLE.extra`); find three crystal shards past the Salvager's searchlight sentries, beat the Foreman, and the core lights. Part 4 (unlocks 9 Dec): the Salvager finale on Crash Isle. Four boss fights start when you walk up to their beacon (`FIGHT` and `fightStep` in the season file): the scrapper ambush on the west beach (waves), the Hauler on the barge (now out off the west beach, deck at sea level, ferry stop `barge`; armoured front, charge lanes, slam rings, crew in cover), the Foreman (searchlights call strikes, crystal pylons shield him, then a blade phase) and the Salvager (drone swarm and magnet, then a mech with four joints, then him while the crater floods). Each has an intro and an outro scene (`scene(id, shots, done)`, `SCN`): they play once and can be replayed from the Season tab, like the Landfall cutscene. The Season tab also plays a Season 1 trailer (`trailer()`, about 45 seconds of the same scene engine). Fights award the season's weapons, and the skins: Crater Scout when the core is lit, Meteor Glow for beating the Foreman without being spotted, Salvager's Rig for the finale.
- **Season 2 · High Water** (`seasons/s02.js`, 16 Dec – 12 Jan): the first time you're in the city a cold open plays (a friend's highrise, the wave through the tear, the window bursting, the fall) and you wake on a plank in a flooded city. Part 1: the boat on a billboard, the survivors' rooftop camp (Frank gives you the harpoon gun: F, or the Harpoon button), three rescues and the great shark. Part 2: Brine's raiders and First Mate Sable. Part 3: diving gear, three valves at the pump house, Ironjaw. Part 4: Captain Brine's ship off the west coast in three phases, then the city drains; the sunken district with his wreck stays (`buildTrace`, also built in past mode). Hearts and knockouts (you wake on the nearest roof), sharks and splash attacks all live in the season file. Skins: Diver, Canal Captain (Part 1 without a bite), Brine's Coat. Its trailer (`trailer()`, and the video `seasons/s02-trailer.mp4`) is in the Season tab.
- **Season 3 · The Syndicate** (`seasons/s03.js`, 13 Jan – 9 Feb): after the drain the Marigold Syndicate owns the city. The cold open plays the first time you're on the street (a collector tips a chai cart, Inspector Reyes's jeep pulls up) and that spot becomes Market Street (`st.home`); `places()` picks four more districts, the counting house (Old Town) and Marigold's tower (the tallest building near the middle). Each district has four rackets (`RK`: collection, box, crew, rescue); three free it (stamps off, stalls back). Heat (`st.heat`, one to three marigolds) brings ambushes (alley, van, a "chaiwala" plant, snipers) and cools with time or in the garage. Part 1: the market chase (barricades to vault, shutters to slide under, via `R.pk.low`/`R.pk.gap`), the raid and Brass. Part 2: the counting-house heist (guard sight cones, one-hit takedowns from behind, flashbangs, the alarm), the Ledger (Mr. Whitlock), the fight you lose and Reyes's jeep. Part 3: Rosa gives the rope launcher and the Comet; three convoys (drop on them from a roof via `R.pk.onLand`, or tyre spikes from the Comet, F), one a decoy; then Velvet's chase on the road graph (`BLC.nodes`). Part 4: the lobby, the swing route past the snipers, the rooftop chase, Marigold in her greenhouse, and the finale (her fall, Reyes runs, the lights go out). The trace is the dark tower ("Reyes") and marigold graffiti. Skins: Undercover, Clean Hands (heist unseen), Marigold's Suit. Its noir trailer (`trailer()`, and the video `seasons/s03-trailer.mp4`) is in the Season tab.
- **Moves for the seasons** (`PK`, `R.pk`, in `index.html`): slide (sprint, then crouch; knocks fight units down) and vault (sprint at a `PK.lows` box) run in `pkStep` after movement; `PK.gaps` block you unless you're sliding. Both are checked in `blrValid`. The rope launcher (`R.pk.rope(true)`, `ropeOn()`) reuses the Bangalore web swing (`webStart`, `SW`, `swingCore`: roof walking, falling off edges) with a rope-coloured line, outside the flood only; `PK.onLand(at, roofHeight, fallSpeed)` hears every landing. Cars with `nitro` (the Comet, `VT.comet`, `VDRIVE.comet`) boost with Shift or the Nitro button; the Comet gets a garage bay once `ru-season` has `s3.comet` (`garList`, `garComet`).
- **Bodies and the crowd.** `avBuild` (after `avRealism`) gives avatars a build (`build: { h, w, belly, sh, head }`, on the outfit or on a look) and pieces (`coat`, `kurta`, `saree`, `vest`, `cap`/`peak`, `glasses`, `beard`, `moustache`, `flower`, `sleeveless`, hair `bun`/`ponytail`/`curly`/`side`); the body sits in a scaled inner group with the head scaled back, so `g.scale` is left alone. Fight heroes otherwise inherit the player's skin and hair through `heroLook`, so cast outfits set `skin`, `hair` and `hairCol`. `crowdLook(i)` varies all of this by index, and the instanced pedestrians get widths, heights, bellies, beards, glasses, caps and buns (`pedLook`).
- **Hitting people in the street.** F (or the Punch button on phones) when you face someone close (`pedTarget`, `pedPunch`): kids, older people and anyone on the phone fall down (`mode: 'down'`) and then run; others run (`'flee'`) or fight back, which is a real `ssFight` against them and their chat group (`pedBrawl`, heroes `pedb0`–`pedb2` built from their look). The loser lies down, bystanders scatter (`pedScatter`) and the police heat goes up.
- **The phone is a phone.** It opens on a home screen (clock, date, app grid with unread badges, wallpaper in the season's accent) under a status bar (signal, "No service" in the flood, a battery that drains outside and charges in your room). Apps: the old tabs (there is no News app any more) plus Messages (threads in `PHX.th`, canned replies in `REPLIES`, banners via `phBanner`), Flock and Weather. `phxRules` sends Mum's and the unknown number's messages as things happen. Everything is saved in `ru-phone`. Seasons add messages and posts with `R.phone.msg(thread, text, from)` and `R.phone.post(handle, name, text, img)`.
- **Flock, the social network** (`phFeed`): accounts with bios, follower counts and ticks (`ACC`); Home with For you and Following (`PHX.fo`, default `FOLLOW0`); threads with replies (`fkReplies`) and a reply box (`PHX.ur`); profiles with Follow; Explore (trending tags counted from posts, search, who to follow); Notifications (`fkNotes`: likes, replies and follows on your posts, a badge and a banner via `flockTick`); and composing a post (`PHX.my`, with suggestions from `fkSuggest` and optionally the last photo from photo mode, `PHOTO_LAST`). Everyday posts come from `FLOCK`, season posts from `phFeedPosts`, and the news is the Bangalore Bulletin's posts (`fkNews`). Numbers on other people's posts are fixed by their id; yours fill in over the first half hour. The view state is `FK` (with a back stack the phone's back button walks).
- **Jail.** Hitting people builds a record (`JAIL.rec`, saved as `ru-record`; a punch adds 1, a knockout 2, and it fades by 1 every 90 seconds). With a record of 3 or more, being caught by the police (`busted`) sends you to a cell; at 8 they come straight after the fight. The cell is an underground level (`LVL.jail`, `jailBuild`, `jailGo`) and there's no sentence: you break out (`jailStep`). Work the loose bar five times (E) while the guard has his back to you (he turns round every 5 to 9 seconds, `JAIL.look`), squeeze through the gap (`J_GAP` joins the cell and corridor rects), take the keys off his desk and unlock the door. If he sees you out of the cell or at the bar, he puts you back and the bar is fixed (`jailCaught`). After four minutes he falls asleep. Getting out (`jailOut`) puts you back where you were picked up with three heat; the record stays.
- **Season themes (the whole site changes each season, from Season 2).** `SEASON_THEMES` (next to `seasonInfo`) gives each season light and dark colour tokens, body and display fonts (loaded from Google Fonts only while it runs), a CSS grade on the 3D canvas (`#scene`, off with Reduce effects via `html.lowfx`) and the room's accent wall. `seasonTheme(n)` runs at page load and sets `html[data-season]`. A season file's own overlays (like Season 3's noir trailer) must use `!important` to beat the grade.
- **Scene cameras** go through `R.camOut([x, y, z])` (`camOut`), which pushes a camera that would sit inside a building out past its nearest wall; building walls are one-sided, so from inside you'd see straight through them.
- **The story.** `SEASON_PLANS.md` opens with the story bible (the spine, cause and effect between seasons, the mythology and its reveals, character arcs, plants and payoffs, and dialogue rules). Read it before writing any season, and keep its plants-and-payoffs table up to date. Dialogue: no catchphrases or villain monologues, subtext over statement, short lines, and every villain has a reason.
- **The flooded city** (`R.flood`, in `index.html` so later seasons can use it): `floodSet(level)` puts the whole map under water. Validity goes through `floodValid` (buildings above the water are walls, submerged ones you swim over; boats only on open water), and `floodStep` sets your height after movement: on a roof, at the surface, or diving (C or Crouch) with a breath meter (`FLOOD.breathTime`). You climb onto a roof near the water or up a ladder (`floodLadder`) with E. Traffic stops and pedestrians hide. Boats and the plank raft are vehicle types `boat` and `raft` (`FLOAT`). `floodLevel` moves the water; `floodOff` ends it.
- **Season fights, weapons and skins** (in `index.html`, so they outlast the season): `R.fight(o)` (`ssFight`) stages a boss fight in the real streets on top of the street-boss engine (`startEvent('st', …, { part: 'q' + id, site, ss: 1 })`, centred on `o.at` in map coordinates, so the fight works in local coordinates round it). `o` gives `boss` stats and `outfit`, extra `units`, `cover` ([x, z, 'crate' | 'car' | 'none', r]), `setup`, `step(dt, F)`, `hit(u, d, from, F)`, `kill`, `hud`, `goal`, `intro` and `end(won)`; `F` is the helper object (`add`, `mark` = `sbMark`, `hurt`, `near`, `win`, `cover`, `move`, `kill`…). Units with `cover: 1` hide behind cover and lean out to shoot (`ssCover`). The weapons (`SSW`: blaster pistol, scatter gun, scrap rifle, shard sword, heavy wrench, harpoon spear) plug into the fight kit: guns have magazines, reloading (R) and ammo cells; there are hit markers, muzzle flashes and enemies break into scrap. You carry one gun and one melee weapon (Q switches; phones get Fire, Swing and ⇄ buttons, `.sspad`). Owned weapons, the loadout, earned skins (`SSKIN`) and the one you wear live in `ru-arsenal`; the Loadout and Wardrobe cards are appended to the phone's Season tab (`arsTab`), and a worn skin goes over your look (`arsLook`).
- **Your building's garage.** Under your tower (`buildGarage`, level `garage` at `GRY`): a roller shutter next to the HOME door leads down a ramp, and the tower lift has a Garage button (`garGo`). About ten vehicles wait in their bays (`GAR_CARS`) and anything you drove off is put back when you come down again (`garRestock`); a lift door in the garage goes back up to the lobby.
- **The season's trailer in the room.** A projector on the ceiling throws the running season's poster onto the south wall, between the swim medals and the east corner (`seasonPoster`, egg `proj`). The room is built before the season code, so it works out the season itself (`roomSeason`, same start date, `?season=N` too). Clicking it plays that season's video from `TRAILERS` in an overlay (`seasonVideo(src)`, also `R.video`), or says the trailer isn't out yet; each season's tab has the same button. The phone works in the bedroom too (`phRoom()`), with the tabs that don't need the city (Map, Jobs, Camera and Story are hidden there).
- **City life.** Random street events (snatched bags, crashes) are switched off. Driving starts in the driver's seat (V or the view button switches to a chase camera; saved as `ru-drivecam`), and the phone's map has "Bring me a car". The first-person hands are hidden whenever `body.cine` is set.
- **The menu and Style.** The pause menu (`renderPause`, tab in `pTab`) has a header (your name, the season and week, Resume) and tabs: Play (tiles for Style, Phone, camera, photo mode, At a glance, Travel, plus status), Travel (`DESTS`), Gear (inventory and the season loadout), Trophies (`achMenu`) and Settings. Style (`renderLook`, `#lookEl`, tab in `lookTab`) has Look, Skins (the season skins as cards, worn with `arsWear`) and Pet, and opens from the on-screen Style button under Phone (`stBtn`, its dot shows what you're wearing) as well as from the menu. The lair's wall map now shows just home places and the seasons; the Daily Bugle and the multiverse map went with the story modes.
- **The lair is all original** (`lairExtrasBuild`, `lairExtras`, state `LAX`; eggs are `lx:<id>`, handled by `lairEgg` and `lairLabel`). The MCU and DC villains are gone from `BOSSES` (dropped by their `mcu`/`dc` flags; their code and models are unused). The rack weapons keep their ids but are originals now (Storm hammer, Carbon claws, Boomerangs, Scrapyard shield, Homemade web-shooters, Prism Gauntlet; Shadow blade and Storm axe off the rack). The back wall has an RU emblem (three quick taps: party lights); the right wall is the suit gallery, every season skin in a case, earned ones lit and wearable by clicking (`lxSuits`); the left wall has crates for the next three seasons (`LAX_TEASE`, dated from the season start), a corkboard and a safe (code 1811, the day the meteor fell; `ru-lairsafe`, with a note teasing Season 15). By the stairs: the web-shooter bench with a rubber duck, a record deck that plays, and a punching bag. Achievements `duck`, `bag` and `safe`.
- **Graphics settings.** "Reduce effects" (`lowFx`) and "Fancy city graphics" (`fancyFx`, saved as `ru-fancy`, off by default) are in the pause menu. Bloom and colour grading (post-processing), the height-haze shader and the city's sun shadows only run with fancy graphics on. A frame-rate governor (`fpsCheck`) also steps quality down on its own when frames are slow.
- **Persistence.** Everything is in `localStorage` under `ru-*` keys. Every storage access is wrapped in `try/catch`; keep that pattern.
- **External data.** Several features load data from outside the page:
  - Last.fm charts and album covers (filled into `#lfmAlbums` and friends inside the music section);
  - the Mandalink announcements board (`anRender`);
  - `news.json`, the news pill, which Mandalink also reads (give each new message a new `id`; it hides after `until`);
  - the private chat (`chatOpen`, `/#chat`): AES-GCM in the browser, ciphertext stored in Supabase; see `CHAT_SETUP.md`.

## Rules specific to this repo

- **The Mandalink code is frozen.** Don't modify these three regions unless explicitly asked:
  - `function radTile(` … `function toHub(){`;
  - the block from the `猴王闹海岛: the Mandalink story` banner comment to `// ---------- input ----------`;
  - `function enterWorld(){` … `function exitWorld(){`.
  To verify, compare those slices against `git show 4d3c6d1:index.html`.
- Never put the chat password in the repo or site, and never use the Supabase `service_role` key; only the public anon key belongs in the page.
- Content must be factual: don't invent achievements, dates, numbers or credits for Rayan, and don't credit mentors or teachers.
- Phones must work: no horizontal scroll at 390px, touch controls intact, safe-area insets respected.
- When you remove code, check nothing is left undefined: run eslint's `no-undef` rule over the extracted inline scripts and compare against the previous run (a handful of names were already undefined before; only new ones matter).
